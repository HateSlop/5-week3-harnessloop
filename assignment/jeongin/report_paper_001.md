# [리포트] ReAct: Synergizing Reasoning and Acting in Language Models
- 저자: Shunyu Yao, Jeffrey Zhao, Dian Yu, Nan Du, Izhak Shafran, Karthik Narasimhan, Yuan Cao
- 발표연도: 2022년
- 출처: ICLR 2023, arXiv:2210.03629

## 1. 핵심 요약
ReAct는 대규모 언어 모델 내에서 추론(Reasoning)과 행동(Acting)을 통합하여, 두 가지 기능을 교차적으로 수행하는 혁신적 프레임워크이다. 모델은 Thought-Action-Observation 순환 과정을 통해 외부 도구와 상호작용하며, 이를 통해 정보의 동적 갱신 및 복잡한 문제 해결이 가능해졌다. 이 접근법은 기존 언어 모델의 환각 현상을 줄이고 결과의 해석 가능성을 높인다.

## 2. 주요 연구 내용 및 의의
이 논문에서는 기존의 순수 추론이나 행동 모델이 가지는 한계를 극복하고자 ReAct 방식을 제안했다. 추론만 수행하는 모델은 내부 지식에 한정되어 환각이 발생할 수 있고, 순수 행동 모델은 장기 계획 수립이 어려웠다. ReAct는 [Thought -> Action -> Observation]의 루프를 통해 모델이 외부 환경과 상호 작용하고, 실시간 피드백을 받아 복잡한 질의에 대응한다. HotpotQA, Fever 등 다중 근거 추론 벤치마크에서 성능 향상과 환각 최소화 효과를 확인했다. 이는 자연어 처리 분야에서 지식과 행동의 통합으로 AI 에이전트의 실용성을 한 단계 끌어올린 기여로 평가된다.

## 3. 한계 및 시사점
ReAct는 도구 호출 시 지연과 토큰 사용량 증가 문제를 내포한다. 특히 다단계 행동이 늘어날수록 에러가 누적될 가능성이 존재하며, 이는 전체 성능 저하로 이어질 수 있다. 향후 연구에서는 효율적인 토큰 관리와 오류 수정 메커니즘 개발, 그리고 다양한 도메인에의 확장성을 탐구하는 것이 필요하다.
